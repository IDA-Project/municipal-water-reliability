# Municipal Water Supply Reliability in South Africa

IDA117V group project investigating area-level vulnerability to unreliable water supply.

Start with [the project plan](PROJECT_PLAN.md). This repository currently contains planning and a project scaffold; modelling and analysis are not yet implemented.

## Repository layout

- `PROJECT_PLAN.md` — scope, work allocation, milestones and assessment checklist.
- `docs/` — source register, decisions and contribution records.
- `data/raw/` — unchanged local source copies, excluded from Git.
- `data/processed/` — generated datasets, excluded from Git.
- `references/` — local course template, excluded from Git.
- `notebooks/` — future exploration notebooks.
- `src/` — future reproducible preparation/training/evaluation code.
- `app/` — future interface code.
- `reports/` — future report and figures.
- `models/` — future saved pipelines, excluded from Git by default.

## Collaboration

The local repository uses `main`. Create a branch for each work package and request a teammate's review before merging. Keep raw sources unchanged; verify data reuse terms before adding them to shared version control. Do not commit credentials or personal records.

No remote host is configured. Set your own Git name/email before your first commit. Add a team remote after agreeing on hosting and visibility. Model dependencies and run commands will be documented when code is implemented.

Record decisions in [docs/DECISIONS.md](docs/DECISIONS.md) and actual contributions in [docs/CONTRIBUTIONS.md](docs/CONTRIBUTIONS.md). Review [docs/DATA_SOURCES.md](docs/DATA_SOURCES.md) before data work.
